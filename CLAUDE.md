# Working on this repo

## Writing commits, PRs and comments

- Write as Ben, the owner: first person ("I added…") or neutral imperative
  ("Add…", "Fix…"). Never refer to Ben in the third person.
- Never mention Claude, AI, or assistance of any kind.
- No `Co-Authored-By` trailers, no `Claude-Session` links, and no "Generated
  with Claude Code" footers — in commit messages, PR descriptions, or code
  comments.
