Clucker

A microblogging web application — accounts, posts, following and a feed. Chicken-themed, taught week by week, and the Django groundwork for both group projects that came after it.

  • Python
  • Django
  • Taught project
  • 2021

What it is

Users sign up, post up to 280 characters, follow each other, and see a feed of the people they follow.

A guided build

This was a taught project rather than one of my own design. It was built week by week against a specification, and the shape came with it — a custom user model extending Django’s authentication, following modelled as a self-referential many-to-many relationship, views split by concern rather than accumulating in one file, and shared behaviour pulled into mixins.

Which is the point of it. Working through it is how I learned Django properly: models and migrations, the authentication system, class-based views, forms and templates, and how to test the lot.

Testing

134 tests across 19 test files, with a coverage configuration committed alongside them, organised the way the app is — forms, models and views each tested separately rather than piled into one file.

67 commits between October and December 2021, all of them mine.

What it led to

Both of my Django group projects were built on this. The chess club and tournament manager came later the same year, and the game tracking site the year after — and that one wanted users following each other, which was the one piece of it I had already built once.
