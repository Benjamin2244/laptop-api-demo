Clucker

A microblogging web application — accounts, posts, following and a feed. Chicken-themed, and built during my BSc.

  • Python
  • Django
  • 2021

What it is

Users sign up, post up to 280 characters, follow each other, and see a feed of the people they follow. Small in scope on purpose — the interesting part was building all of it properly rather than building a lot of it.

How it is put together

  • A custom user model extending Django’s authentication, with following modelled as a self-referential many-to-many relationship — so one table expresses the whole social graph.
  • Views split by concern — authentication, account, posts, follows, feed — rather than accumulating in a single file.
  • Shared behaviour pulled into mixins instead of being repeated across views.

Testing

134 tests across 19 test files, with a coverage configuration committed alongside them.

They are organised the way the app is — forms, models and views each tested separately, rather than piled into one file.
