Hate speech detector

Decides whether a piece of text is hate speech, and separately whether it is aimed at the LGBTQIA+ community. Built during my BSc.

  • Python
  • NLTK
  • 2023

Two questions, not one

Most detectors answer a single question: is this hate speech? This one answers that, and separately asks whether the text is directed at the LGBTQIA+ community.

Keeping them apart matters. Text can be about the community without being hateful, and hateful without being about it — collapsing both into one score would lose that distinction entirely.

How it decides

Text is parsed into words and scored against reference corpora, with WordNet used to widen matching beyond exact wording so related terms are not missed.

  • Three separate thresholds — word score, hate speech, and positive speech — each adjustable at runtime.
  • Sensitivity is therefore a setting rather than something baked into the code, which matters for a judgement this subjective.
  • It checks for a connection at startup and only downloads language resources if there is one, so it still runs offline.

Data and testing

Tested against a large public corpus of 1.6 million tweets and a set of LGBTQ-related Reddit comments, giving both general text and text specific to the second question.

40 unit tests with coverage measured, covering the parsers, both detectors, and the result handling as separate units.
